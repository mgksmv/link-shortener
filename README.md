# Инструкция

## При первичном запуске нужно инициализировать проект командой `make init` <br />
Окружение:<br />
`dev` - разработка<br />
`prod-http` - продакшн с IP адресом без домена<br />
`prod` - продакшн с доменом<br />

По дефолту выбирается `dev` <br /><br />

### Инициализация проекта
```
make init
```

### Запуск проекта
```
make up
```

### Остановка проекта
```
make down
```
### ⚠️ Остановка проекта с очисткой данных (файлов хранилища, базы данных и т.д.)
```
make down-clear
```

### Перезапуск проекта
```
make restart
```

### Пересборка проекта
```
make build
```
