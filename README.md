# Link Shortener - веб-приложение для создания коротких ссылок

Данное веб-приложение позволяет создавать короткие ссылки для сокращения длинных URL-адресов и упрощения их передачи. Приложение предоставляет удобный интерфейс для создания коротких ссылок, а также возможность просмотра статистики переходов по каждой ссылке.

### При первичном запуске нужно инициализировать проект командой `make init` (проект работает на Docker'е)<br />
Окружение:<br />
`dev` - разработка<br />
`prod` - продакшн<br />

По дефолту выбирается `dev` <br /><br />

### Инициализация проекта
```
make init
```

### Запуск проекта
```
make up
```

### Остановка проекта
```
make down
```
### ⚠️ Остановка проекта с очисткой данных (файлов хранилища, базы данных и т.д.)
```
make down-clear
```

### Перезапуск проекта
```
make restart
```

### Пересборка проекта
```
make build
```
